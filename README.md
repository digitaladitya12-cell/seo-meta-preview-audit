# SEO Meta Preview & Audit

A lightweight, browser-based tool to preview a search snippet and run quick SEO checks.

## Features
- Live title and meta description preview
- Character counts
- Primary keyword checks in title, description, and H1
- H1, canonical URL, and robots directive reminders
- Runs locally in your browser; it does not send form data to a server

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Enter page details and review the preview and checklist.

## Limitations
This is a manual-input checker, not a crawler. It does not fetch a URL, inspect rendered HTML, measure Google pixel-width truncation, or guarantee rankings. Google may rewrite title links and snippets.
